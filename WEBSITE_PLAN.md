# Nasim Vision — план официального сайта

Дата: 2026-09-18. Статус: структура согласована, код ещё не написан.
План продукта (коробки) — в `PLAN.md`. Этот файл только про сайт.

---

## 1. Задача сайта

Витрина, которая приводит к разговору. Владелец ресторана за 30 секунд должен понять,
что это, поверить, что видео никуда не уходит, и оставить заявку.
Сайт ничего не продаёт кнопкой, он собирает заявки на демо.

---

## 2. Принятые решения

| Вопрос | Решение |
|---|---|
| Главное действие | Форма заявки на демо (имя, телефон, заведение) как основная + кнопка WhatsApp рядом |
| Структура | Один лендинг + обязательные страницы Impressum и Datenschutz |
| Цены | Два тарифа с ценой «от», без точных цифр до расчёта себестоимости |
| Визуал | Макет панели в первом экране, схема приватности отдельным блоком, точечно фото заведений |
| Языки | Немецкий основной, английский второй, переключатель в шапке |
| Стек | Astro + Tailwind, статика |
| Хостинг | Vercel, проект `website`, деплой из GitHub при каждом пуше. Root Directory = `website`. Настройки сборки в `website/vercel.json`, не в панели |
| Форма | Серверная функция Vercel: письмо на почту + сообщение в Telegram. Без сторонних форм-сервисов |
| Аналитика сайта | Без cookies. Vercel Web Analytics или Plausible. Тогда не нужен cookie-баннер |

## 4. Блоки лендинга сверху вниз

Тексты ниже — рабочие, на русском для понимания. На сайте будут DE и EN.

**1. Шапка.** Логотип, переключатель DE/EN, кнопка «Demo anfragen».

**2. Первый экран (hero).**
Заголовок: «Сколько гостей у вас сегодня? Точный ответ, без облака».
Подзаголовок: коробка подключается к вашим камерам и считает посещаемость. Видео не покидает заведение.
Кнопки: «Запросить демо», «Написать в WhatsApp».
Визуал: макет панели на телефоне и планшете (график за день, «сейчас внутри»).

**3. Проблема.** Три коротких карточки.
«Камеры есть, цифр нет». «Не знаете, в какой час нужен второй бармен». «Не видите, сработала ли акция».

**4. Как это работает.** Три шага с иконками.
Подключаем коробку к вашему сетевому свитчу → рисуем линии входа на камерах → вы смотрите цифры с телефона.
Подпись: установка за один визит, ваши камеры и регистратор остаются как были.

**5. Приватность.** Ключевой блок, самое сильное отличие.
Схема: камеры → коробка в вашем заведении → ваш телефон. Стрелка «в интернет» перечёркнута.
Три тезиса: видео не сохраняется, лица не распознаются, наружу уходит только «я работаю, версия 1.2».
Подпись про GDPR: только счётчики, не персональные данные.

**6. Что вы увидите.** Скриншоты/макеты панели с подписями.
Сейчас внутри. Посещаемость по часам. Сравнение с прошлой неделей. Ночная сводка от помощника.

**7. Для кого.** Четыре карточки: рестораны, бары, отели, магазины.
У каждой одна фраза про их задачу. Позже вырастут в отдельные страницы.

**8. Тарифы.** Две карточки.
- **Standard** — до 4 камер, панель, сводки. «от ___ € установка, от ___ €/мес».
- **Pro** — до 8 камер, всё из Standard + чат с помощником на коробке. «от ___ € установка, от ___ €/мес».
Подпись: точная цена после осмотра объекта, без скрытых платежей.

**9. О нас.** Два-три предложения. Вена, локальная команда, приезжаем сами. Фото или без.

**10. Заявка.** Форма: имя, телефон или email, название заведения, город, сообщение (необязательно).
Кнопка «Запросить демо». Рядом кнопка WhatsApp. Чекбокс согласия на обработку данных (обязателен для DSGVO).

**11. Подвал.** Impressum, Datenschutz, контакты, языки.

## 6. Обязательное по праву Австрии

- **Impressum** (§5 ECG, §25 MedienG): название фирмы или ФИО, адрес, email, телефон, форма предприятия, UID при наличии.
- **Datenschutzerklärung** (DSGVO): что собираем через форму, зачем, сколько храним, права пользователя.
- **Cookie-баннер не нужен**, если аналитика без cookies и нет сторонних скриптов.
- Форма: явное согласие чекбоксом.
