# Nasim Vision

Локальная коробка для аналитики посещаемости по камерам (Вена, HoReCa и ритейл).
Видео и данные не покидают объект.

## Правила работы

- **Сначала прочитай `PLAN.md`** (продукт, коробка) и `WEBSITE_PLAN.md` (сайт). Это единственные источники правды по решениям.
- Планы реализации лежат в `docs/superpowers/plans/`. Текущий: `2026-09-18-website-skeleton.md`.
- Структура репозитория: `website/` — сайт на Astro, деплоит Vercel (Root Directory = website); `box/` — софт коробки на Python.
- Деплой сайта: пуш в `main` → боевой домен, другие ветки → тестовый адрес Vercel.
- Репозиторий: https://github.com/NSM1276/nasim.at. Прежний сайт-визитка Nasim Nuridinov удалён по решению владельца 18.09.2026.
- Vercel: проект `website`, Root Directory = `website`. Настройки сборки держим в `website/vercel.json`, он имеет приоритет над панелью Vercel. В панель ничего не выносим.
- Домен `nasim.at` пока не привязан к проекту. Работаем на адресе проекта Vercel.
- Ручные шаги владельцу не выдавать. Искать способ сделать самому: MCP-инструмент, CLI или конфиг в репозитории.
- Общение с пользователем на русском языке.
- Код не пишется, пока пользователь явно не попросил. Сначала обсуждение, план, согласование.
- Любое изменение архитектурного решения вносится в `PLAN.md`, а не остаётся только в чате.
- Готовые open-source библиотеки предпочтительнее своего кода.
- Никаких кадров, видео и лиц в хранилище. Только события и счётчики.
